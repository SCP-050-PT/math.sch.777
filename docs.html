Установка и запуск

Приложение написано на чистом PHP (Backend) и JavaScript (Frontend), что обеспечивает максимальную совместимость с любыми хостингами.

Системные требования

  • Веб-сервер (Apache, Nginx, OpenServer, XAMPP).
  • PHP версии 7.4 или выше.
  • Доступ на запись в директорию data/.

Инструкция по первому запуску

  1. Скопируйте все файлы проекта в корневую папку вашего веб-сервера.
  2. Убедитесь, что папка data/ существует. Если её нет, скрипт создаст её автоматически, но права на создание папок должны быть у PHP.
  3. Откройте в браузере адрес: http://ваш-сайт/admin.php.
  4. Система автоматически сгенерирует файлы конфигурации.
Внимание: При первом входе используются стандартные данные администратора:
Логин: admin
Пароль: admin
Настоятельно рекомендуется сменить их в настройках профиля сразу после входа.

Панель управления учителя

Центр управления учебным процессом. Доступен по адресу admin.php.

Основные возможности:

Обзор (Дашборд)

Показывает сводную статистику: общее количество учеников, количество решенных примеров за все время, средний балл по школе и график активности за неделю.

Управление классами

Создание, редактирование и удаление классов. При удалении класса удаляются и все привязанные к нему ученики.

Администраторы

Система поддерживает несколько учителей. Вы можете добавить коллег, выдав им логин и пароль. Любой админ может управлять всем процессом.

Настройки профиля

Смена логина и пароля для текущего авторизованного учителя.

Работа с учениками

Вкладка "Ученики" позволяет управлять составом классов.

Добавление ученика

При создании ученика необходимо указать ФИО и выбрать класс. Система автоматически сгенерирует уникальный 4-значный PIN-код. Этот код используется учеником для входа в систему (пароли не используются для упрощения доступа детям).

Экспорт списков

Для удобства учителя предусмотрены кнопки быстрой выгрузки:

  • Скачать список всех учеников: CSV файл со всей школой.
  • Скачать список класса: CSV файл только выбранного в фильтре класса.

Файл содержит колонки: Класс, ФИО, PIN-код. Этот файл можно распечатать и раздать детям данные для входа.

Проведение экзаменов

Экзамен — это специальный режим, который принудительно активируется учителем для целого класса.

Механика: Когда учитель запускает экзамен для класса "2 А", у всех учеников этого класса в главном меню появляется большая кнопка "ЭКЗАМЕН", а остальные режимы блокируются (опционально) или становятся второстепенными.

Параметры запуска:

  • Класс: Для кого проводим.
  • Сложность: Легко, Средне, Сложно.
  • Время: Таймер (1, 3, 5, 10, 20 минут).

Завершение и результаты:

Учитель может вручную остановить экзамен кнопкой "Завершить". После этого экзамен переходит в архив, и доступен отчет с результатами каждого ученика (количество верных ответов и оценка по 5-балльной шкале).

Отчеты и экспорт данных

Система генерирует подробные CSV отчеты, совместимые с Microsoft Excel.

Виды отчетов:

  1. Общий отчет: История всех решений всех учеников за всё время.
  2. Отчет по ученику: Детальная история конкретного ребенка (доступна из карточки ученика).
Техническая деталь: При формировании CSV дробные числа (например, средний балл 4.5) записываются с запятой (4,5). Это сделано для того, чтобы Excel корректно распознавал их как числа, а не конвертировал в даты (например, "4 май").

Игровые режимы

Приложение предлагает 9 разнообразных механик для удержания интереса ребенка.

Режим Описание Особенности
Свободный Базовая тренировка без ограничений по времени и жизням. Идеально для разминки.
На время Необходимо решить максимальное количество примеров за заданное время. Таймер обратного отсчета.
Выживание Игра продолжается до 3-х ошибок. Индикатор "сердечек".
Верю - Не верю Показывается готовый пример (напр. 5x5=26). Нужно быстро ответить, верно это или нет. Кнопки ДА/НЕТ вместо цифр. Развивает внимательность.
Поиск X Уравнения вида ? × 6 = 42. Нужно найти множитель. Подготовка к делению и алгебре.
Битва с Ботом Соревнование с ИИ. Бот наносит урон игроку по таймеру. Правильные ответы игрока наносят урон боту. Полоски здоровья (HP), анимация робота. Эффект напряжения.
Найди Пару (Memory) Сетка перевернутых карточек. Нужно найти пары "Пример" и "Ответ". Тренировка зрительной памяти.
Мат. Дождь Примеры падают сверху экрана. Нужно успеть ввести ответ и "сбить" пример лазером до касания земли. Аркадная механика. Тренировка скорости набора на клавиатуре.
Конструктор Дано число (ответ). Нужно выбрать из списка все примеры, результатом которых является это число. Развивает навык декомпозиции числа.

Система достижений

Для мотивации учеников реализована система из 30+ наград (ачивок). Проверка выполнения условий происходит автоматически после каждого завершения игры.

Категории наград:

  • Прогресс: За общее количество решенных примеров (Новичок, Мастер, Легенда).
  • Точность: За решение тестов без единой ошибки (Снайпер, Аимбот).
  • Скорость: За высокую скорость решения в режиме "На время" (Флэш).
  • Уникальные:
    • Зонтик — продержаться 3 минуты под дождем.
    • Шерлок — решить 50 уравнений с поиском X.
    • Сова / Жаворонок — за игру поздно ночью или рано утром.

В профиле ученика отображается редкость получения достижения среди одноклассников (в процентах).

Справочник API

Взаимодействие фронтенда и бекенда происходит через единую точку входа api.php. Все запросы отправляются методом POST с телом в формате JSON.

Формат запроса:

POST /api.php
{
    "action": "название_метода",
    "param1": "значение",
    ...
}

Основные методы:

  • student_login — авторизация ученика (params: pin, class_id).
  • admin_login — авторизация учителя (params: login, password).
  • get_initial_data — получение списка классов для формы входа.
  • get_student_profile — загрузка статистики, истории и ачивок ученика.
  • save_result — сохранение результата игры. Возвращает новые ачивки, если они получены.
  • get_admin_dashboard — получение всех данных для админки (ученики, классы, статистика).
  • manage_class — (add/edit/delete) управление классами.
  • manage_student — (add/delete) управление учениками.
  • manage_admin — (get/add/delete) управление списком администраторов.
  • export_student_list — генерация CSV со списком класса.
